# PHOS Energia — Proposta comercial

Site de proposta comercial da Pulse Marketing para a PHOS Energia, desenvolvido em HTML, CSS e JavaScript, sem dependências de build.

## Visualização

Abra `index.html` no navegador ou sirva esta pasta com um servidor estático. Por exemplo, com Python instalado:

```sh
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Arquivos principais

- `index.html`: conteúdo e estrutura da proposta.
- `redesign.css`: identidade visual e estilos responsivos.
- `cinema.css`: apresentação resumida e detalhes expansíveis.
- `clarity.css`: ajustes de legibilidade e fluxo.
- `hero-background.css`: enquadramento da imagem da abertura.
- `app.js`: navegação, WhatsApp e preparação para impressão.
- `hero-cinematic.png`: imagem da abertura enviada pelo cliente.
- `pulse-logo-transparent.png`: logo oficial enviada pelo cliente.

As imagens e a marca foram fornecidas para esta proposta. Sua presença no repositório não concede autorização geral de reutilização.

## Publicação

O site é estático: use a raiz desta pasta como diretório público, sem comando de build. Este repositório não configura publicação automática nem altera o acesso do site já hospedado.

## Escopo comercial

Publicação no Instagram, TikTok, LinkedIn, Google Meu Negócio e Threads, com até 24 conteúdos por ciclo e gestão de Meta Ads. A apresentação tem caráter comercial e informativo; não é um contrato.
